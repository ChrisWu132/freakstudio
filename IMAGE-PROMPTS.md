# Image brief — Contract Manufacturing Landing

Six image slots. Every slot below lists: **where it sits**, **export size**, and the **generation prompt** (copy-paste into Midjourney / Firefly / any image model). The same text is printed inside each placeholder in the design.

**Global art direction (append to every prompt if the model allows a style line):**
`Realistic documentary photography, cool neutral daylight, no logos or brand marks, no stock-photo handshakes, no 3D clip-art, no text overlays, high detail, natural colour grading.`

## Consistency checklist
1. **Factory shots (01, 02):** same cool daylight grading, same shallow depth of field. Shoot or generate them as a pair so the two sections read as one site visit.
2. **Product shots (03–05):** identical pure-white background, identical light direction (upper left), identical shadow softness. Product occupies ~70% of frame width in all three.
3. Case-study cards sit on `#F5F7FA`, so keep the product-shot background pure white (`#FFFFFF`) for a visible edge.
4. Any photo that later carries text on top gets a 25% black overlay — do not bake the overlay into the file.
5. No client logos anywhere until real permission exists; the trust bar uses text category badges on purpose.
