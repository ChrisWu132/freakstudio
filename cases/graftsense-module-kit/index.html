GraftSense sensor module kit

GraftSense is a modular hardware kit of sensor modules, expansion boards and learning resources for STEM teaching and rapid prototyping. Modules share a Grove-style connector, so students and engineers can plug sensors into a controller board and get a working demo quickly. The team ships individual modules, 20–30 module kits, course materials and documentation.

Tech stack

Module library
300+ sensor, display, motor-driver and expansion modules
Interface
Grove / multi-interface connectors
Controller boards
GraftPort expansion boards for Raspberry Pi Pico (RP2040), incl. an Ethernet version
Firmware
MicroPython and Arduino
Design files
Schematic, PCB layout and user docs per module

What we built

  • Custom PCB design for each module
  • Sensor selection and integration
  • Embedded firmware in MicroPython and Arduino
  • Technical documentation and teaching materials
  • Sample code, testing and application support
  • Kit structure planning and supply-chain coordination
