Lidar line-following car.

A four-wheel robot car with a lidar and a custom control board. Our engineers designed and built it, from board and firmware to enclosure and packaging, and delivered the batch.

Tech stack

Main controller
STM32F103RCT6
Sensors
Lidar, line-tracking sensors, MPU6050 IMU, wheel encoders, ultrasonic sensor port
Drive
4-wheel chassis, DC motors with dual encoded motor-driver ports
Control
PID closed-loop speed control; modes for manual/app control, lidar avoidance, lidar follow, wall following, CCD and electromagnetic line tracking
Wireless
Bluetooth module for app / remote control
Power
6–16 V DC input, 5 V 5 A output, voltage monitor
Interfaces
Display port, buzzer, SWD debug, USB download, reserved serial port

What we built

  • Device-side software: embedded control, drivers and application logic
  • Controller board architecture: sensors, motor drive and power design
  • Chassis selection, mechanical installation and calibration
  • PID motor tuning for closed-loop speed control
  • Lidar data acquisition and processing
  • Obstacle-avoidance algorithm with real-time perception and path planning
  • Multi-sensor line-following algorithm
  • Motor driver design with encoder feedback and protection
  • Functional testing, performance tuning and demo
