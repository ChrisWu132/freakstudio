PixelSky AI pixel light board

PixelSky is a pixel LED board paired with a browser-based editor. Users draw or generate animations with AI from text or images, preview them live, and push them to the board, which can also show the time and weather. The team built the whole stack: custom LED matrix PCB, ESP32 runtime, web editor and enclosure.

Tech stack

Main controller
ESP32
Display
Custom 16 x 8 RGB LED matrix PCB with light grid and diffuser
Device firmware
MicroPython on ESP32
Web app
React web editor (local-first) with real-time preview
AI
AI animation generation from text or images to LED
Output
Export to JSON and device code

  • ESP32 MicroPython device-side code
  • React web editor and helper/service tools
  • 3D enclosure, light grid, diffuser and acrylic panel
  • Prototype assembly and validation
