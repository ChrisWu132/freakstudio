Mecanum robot-arm car teaching kit

A teaching kit built around an Arduino UNO mecanum-wheel car with a 3D-printed body, a robotic arm and a separate handheld wireless controller. It is designed for robotics classes, maker labs and hands-on engineering practice. The kit ships with a five-lesson course and courseware.

Tech stack

Car controller
Arduino UNO
Chassis
Mecanum-wheel chassis for omnidirectional movement
Arm
Servo-driven robotic arm with gripper
Handheld controller
Dual joysticks, status display, wireless link, rechargeable battery compartment
Modes
Manual wireless control, obstacle avoidance, line tracking, attitude / angle control, arm operation
Structure
3D-printed housing and mechanical parts, modular expansion interface

What we built

  • Mechanical design: mecanum chassis, robotic arm, 3D-printed housing, module layout, controller enclosure
  • Electronics: car control board integration, wireless communication, motor drive, power distribution, remote controller electronics
  • Firmware: motion control, arm control, wireless control logic, teaching-oriented code structure, extensible module support
  • Five-lesson course: system overview and assembly, mecanum motion basics, wireless controller communication, arm control, structure design and final project
  • Courseware: teaching slides, code, documents and guides
