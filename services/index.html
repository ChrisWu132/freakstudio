Electrical engineering & PCB

For
A dev-board or breadboard prototype that needs its own board, or a PCB that needs revising.
You send
Schematic or PCB files if you have them, photos of what works, a BOM if there is one.
We do
System architecture, schematic, PCB layout, power, sensors, MCU and communication. BOM cleanup, component sourcing and approved alternatives. PCBA and harnesses.
You receive
Schematic, PCB files, Gerbers, BOM with sources, assembled boards.
Cost depends on
Board complexity, number of revisions, part availability.
Not included
Certification testing (FCC/CE), quoted separately. Anything outside the written scope. Major scope changes are re-quoted before work continues.

Firmware & embedded systems

For
Hardware that needs code it can ship with.
You send
Existing code or repository, or a description of how the device should behave.
We do
ESP32 and STM32, C/C++ and MicroPython, BLE and Wi-Fi, sensor drivers, motor control, data protocols, OTA updates, factory test programs.
You receive
Firmware source, factory test program, protocol and API notes.
Cost depends on
Number of features, connectivity, how much existing code can be reused.
Not included
Anything outside the written scope. Major scope changes are re-quoted before work continues.

Testing & manufacturing readiness

For
A working prototype that has to be proven before a batch.
You send
The prototype or its files, and how you expect it to be used.
We do
Power-on, function and communication tests, structural checks, first-article inspection, design-for-manufacturing fixes, an issue log kept until every item is closed.
You receive
Test checklist, test report, test videos, production files.
Cost depends on
How many functions need testing, whether a test fixture is needed.
Not included
Certification testing (FCC/CE), quoted separately. Anything outside the written scope. Major scope changes are re-quoted before work continues.

Pilot & small-batch production

For
A validated design you need more units of.
You send
Approved design files and BOM, or a prototype we built with you.
We do
Parts purchasing, PCBA, harnesses, assembly and packaging. Before the run we agree with you on fixtures, how each unit is tested and recorded, and how units are packed.
You receive
Tested units, batch record, packed shipment.
Cost depends on
Quantity, BOM, test time, packaging.
Not included
Shipping and import duties, certification. Anything outside the written scope. Major scope changes are re-quoted before work continues.
