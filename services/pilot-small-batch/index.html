From an approved prototype to a small batch.

We buy the parts, build and test every unit, and pack the batch, after you approve the design and how each unit will be tested.

Who this is for

A validated design you need more units of: for a pilot with real users, a classroom, a demo fleet or first customers.

Typical starting points

  • Approved design files and BOM
  • A prototype we built with you
  • A previous batch you want repeated

What Anvol does

Prototype vs. batch
A prototype proves the design works. A batch repeats it: the same parts and process, and every unit tested against the targets from the sample rounds.
Hand assembly or PCBA
Chosen per project from board complexity and quantity, and written into the scope. Each machine board-assembly run pays a fixed setup charge, which is part of why small batches cost more per unit.
Fixtures
Whether the run needs assembly or test fixtures is agreed with you before the run.
Testing
Every unit is tested before it is packed.
Records
Each unit's test is recorded, and a batch record comes with every batch. Whether units carry serial numbers is agreed before the run.
Packing and delivery
How units are packed is agreed before the run; the batch leaves as a packed shipment. Fulfillment →
You confirm
The design, before any larger run. Fixtures, testing, records and packing, before the run. Any part substitution, before the part is used. Acceptance of each batch.

Timeline and cost drivers

Timeline
No fixed lead time is published. Part availability, quantity and test time set it, and the date goes in the written scope.
Cost depends on
Quantity, BOM, test time and packaging. The development fee is paid once, so a bigger batch spreads it thinner.
Quantity
No minimum order. Our priced batches were 4, 10 and 15 units; a larger batch is priced for its own quantity. Costs →

What is excluded

  • Shipping and import duties. Usually arranged by you once units leave the factory.
  • Certification testing (FCC/CE). It is done by a test lab and quoted separately when a product needs it.
  • Anything outside the written scope. Major scope changes are re-quoted, with a new timeline, before work continues.
